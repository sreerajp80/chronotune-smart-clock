# Bundled fonts and their licenses

These fonts are bundled in `app/src/main/res/font/` and offered in
Settings → Appearance → Font. Static Regular/Bold weights were used; the
variable-font families were instanced to static weights with `fonttools`.

| Font | License | Source |
|------|---------|--------|
| Inter | SIL Open Font License 1.1 | google/fonts `ofl/inter` |
| Poppins | SIL Open Font License 1.1 | google/fonts `ofl/poppins` |
| Nunito | SIL Open Font License 1.1 | google/fonts `ofl/nunito` |
| Lato | SIL Open Font License 1.1 | google/fonts `ofl/lato` |
| Roboto Slab | Apache License 2.0 | google/fonts `apache/robotoslab` |
| Merriweather | SIL Open Font License 1.1 | google/fonts `ofl/merriweather` |

Full license texts are in this folder.
